# Contribuindo

Obrigado pelo interesse em contribuir com o Cte.Core.

## Issues

Ao abrir uma issue, inclua:

- Versão do pacote.
- Versão do .NET.
- Modal do CT-e.
- XML de exemplo anonimizado, quando possível.
- PDF gerado e descrição objetiva do comportamento esperado.

## Pull requests

Antes de enviar um PR:

- Rode `dotnet build Cte.Core.sln -c Release`.
- Mantenha as alterações focadas em um único assunto.
- Não inclua XMLs reais com dados fiscais ou dados pessoais.
- Atualize README ou docs quando a mudança alterar o uso público.

## Commits

Use mensagens curtas e descritivas, por exemplo:

```text
fix: mapear CIOT do modal rodoviário
docs: atualizar exemplo de logo via stream
```
